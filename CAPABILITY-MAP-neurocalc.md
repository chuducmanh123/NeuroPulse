# Capability Map: NeuroCalc v1 (Clinical Scales & Bedside Calculators — Neuro Ecosystem)

> Spec: [`SPEC-neurocalc.md`](./SPEC-neurocalc.md) · Intent: [`docs/intent/neurocalc.md`](./docs/intent/neurocalc.md) · Module ids are stable — never rename.

| Module id | Responsibility | Depends on |
|---|---|---|
| `calc-data-core` | TypeScript contract (`ScaleRecord`, 6 Granular Blocks, `AssessmentGuide`, `FormulaRule`, `InterpretationBand`, `ScaleReference`), deterministic canonicalization + `section_hashes` + `content_hash` via `src/lib/sync/jsonPatch.ts`, runtime validator, `draft → verified` effective-status gate, and CLI scripts (`calc:validate`, `calc:verify`, `calc:snapshot`) | — |
| `calc-scoring-engine` | Pure zero-UI TypeScript calculation engine: discrete additive point scales (incl. NIHSS `UN` untestable tracking & subscores), ordinal/grade scales, numeric formula calculators with unit conversions & physiological input bounds (ABC/2, corrected Na, corrected Phenytoin, serum osmolality), severity-band resolution, completion progress (`answered/total`), and strict `draft`/hash-mismatch gating | `calc-data-core` |
| `calc-sync-v2` | Supabase PostgreSQL migration (`neurocalc_scale_records`, `neurocalc_scale_revisions`, `neurocalc_sync_state`, `neurocalc_sync_config`, RLS, Realtime, atomic write/restore/purge RPCs + `neurocalc_recompute_root_hash`), Sync v2 repos (`repoSupabase`, `repoMemory`), API routes (`/api/neurocalc/sync/*` with ETag `304`, optimistic `expectedRev` `409`), IndexedDB `IdbLocalStore`, client `SyncEngine` + Realtime hook (`useNeuroCalcScales`), and CLI sync scripts (`calc:migrate-v2`, `calc:pull`, `calc:push`) | `calc-data-core` |
| `calc-shell-ui` | `/neurocalc` route (`layout.tsx`, `page.tsx`), `.medical-journal-app` sticky header (Cyan-Teal `#0E7490`, Night Shift, `AdminButton`, `AppSwitcher`, Admin-only Sync/Offline status badge), search & subspecialty filter bar (reusing `src/constants/subspecialties.ts`), scale directory, Ecosystem Hub & `AppSwitcher` activation (`SOON → BETA`), `DrawLoader` `calc` variant, `MedicalDisclaimerFooter` | `calc-data-core`, `calc-sync-v2` |
| `calc-scorer-ui` | Bedside scoring workspace: full vertical scrollable item list with 1-tap tactile pill/card buttons, numeric inputs with inline unit toggles, completion progress bar (`answered/total`) for long scales, sticky visual live result panel (large `tabular-nums` score, segmented color+icon+label severity bar, concise clinical interpretation, `UN` untestable summary, Reset button — explicitly NO Copy clinical summary button), and pending-verification gating banner | `calc-scoring-engine`, `calc-shell-ui` |
| `calc-assessment-guides` | Selective contextual *"How to assess / ?"* chip rendered only on item-level or option-level clinical pitfalls; inline expandable callout or non-disruptive slide-over drawer preserving active scoring position with text-only structured blocks: (1) bedside exam steps (+ optional text-only exam prompts), (2) edge cases & common pitfalls, and (3) source citation | `calc-data-core`, `calc-scorer-ui` |
| `calc-admin-v2` | New `"neurocalc"` tab inside existing `/admin` (`src/app/admin/page.tsx`) mirroring `NeuroRxAdminSection`: sync health (`rootHash`, `maxSeq`, status counts), granular `section_hashes` inspector, revision history & JSON-patch diff viewer (`HistoryPanel`), quick block text editor (`AssessmentGuide`, `Interpretation`, `Clinical Pearls`, `References`) with 3-way conflict resolution (`ConflictDialog`), and `draft → verified` approval workflow | `calc-data-core`, `calc-sync-v2` |
| `calc-seed-waves` | Source-verified initial neurology scales & formulas (100% original clinical English, text-only assessment guides) + table-driven math verification tests: Wave 1 (Stroke & Neurocritical Care, ~10 scales) and Wave 2 (General Neurology, Neuromuscular, Movement & Metabolic, ~6 scales) | `calc-data-core`, `calc-scoring-engine`, `calc-sync-v2` |

Build order:
`calc-data-core` → `calc-scoring-engine`, `calc-sync-v2` → `calc-shell-ui`, `calc-admin-v2` → `calc-scorer-ui` → `calc-assessment-guides` → `calc-seed-waves`

Data waves (Wave 1 → Wave 2) may be drafted in parallel after `calc-data-core` + `calc-scoring-engine` exist; every scale is gated by automated math tests and human verification (`draft → verified`).
